# 🎓 Student Portfolio Gallery

## 📌 About the Project

The **Student Portfolio Gallery** is a website developed using HTML and CSS to showcase students' profiles, interests, skills, and talents in an attractive gallery format.

Each profile card contains an image, a name, a short description, skill tags, and a button to view an individual portfolio page.

The website features a modern design with gradient colors, rounded cards, hover effects, and a responsive layout that adapts to different screen sizes.

This project was created to practice the fundamentals of web development.

## ✨ Features

- 👥 Displays six student and talent profile cards.
- 🖼️ Includes profile images and descriptions.
- 💻 Shows skills and interests using tags.
- 🔗 Provides buttons to visit individual portfolio pages.
- 🎨 Uses gradient backgrounds and attractive colors.
- 🪄 Includes hover effects on profile cards and buttons.
- 📱 Responsive gallery layout for smaller screens.
- ♿ Includes a keyboard-accessible skip link and visible focus indicators.
- ⚡ Uses lazy loading for most profile images to improve loading performance.
- 🎞️ Supports reduced-motion preferences for users who prefer fewer animations.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure and content of the website.
- **CSS3** – Adds colors, layouts, typography, hover effects, and responsive styling.

## 🚀 How to Run the Project

1. Download or clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `styles.css` are in the same folder.
4. Open `index.html` in a web browser.
5. Click the **View Portfolio** buttons to open the linked portfolio pages.

You can also use the **Live Server** extension in VS Code to preview your website.
